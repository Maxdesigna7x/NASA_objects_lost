# Ruta Fantasma

Abre [index.html](index.html) en el navegador. Juego 2D educativo en español para PC y teléfono. No requiere instalación.

Pilota con WASD, las flechas o el joystick táctil. Frena con Espacio o «Frenar». Pulsa E o el botón de acción al aproximarte. M abre el mapa y Esc abre Pausa. Desde Pausa puedes reiniciar la zona o la expedición.

La ruta pasa por Zacatepec, órbita terrestre, la Luna y Marte. El archivo reúne seis equipos reales. Las ubicaciones dentro del radar, las escalas, la retirada de Envisat y la hiperpropulsión son representaciones de juego. Las fuentes y los créditos se detallan en [DISENO.md](DISENO.md).

Sprites e historieta generados con OpenAI ImageGen. Proyecto educativo independiente.
